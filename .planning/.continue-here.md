## Critical Anti-Patterns

| Pattern | Description | Severity | Prevention Mechanism |
|---------|-------------|----------|---------------------|
| Enum Language Mismatch | Verificar apenas 'MODERATOR' quando backend envia 'MODERADOR' — falha silenciosa | blocking | Sempre verificar AMBAS as variações em CADA ponto de comparação |
| Silent 403 Absorption | React Query hooks retornam [] em caso de 403, mascarando falhas de autorização | advisory | Testar acesso direto a endpoints via curl antes de debugar frontend |
